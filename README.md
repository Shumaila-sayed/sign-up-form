# 📋 Sign-Up Form  

An intermediate **HTML & CSS** project focusing on form design, styling, and basic validation techniques.  

## 🚀 Features  
- **Full-page background image** for a modern UI  
- **Custom fonts & logo section** for branding  
- **Styled input fields** with:  
  - Blue border on focus (`:focus` pseudo-class)  
  - Red border for invalid passwords (`:invalid` pseudo-class)  
- **Form validation basics**:  
  - Password fields highlight errors 🔒  
  - Input styling enhances user feedback  
- **Themed 'Create Account' button** for a cohesive design  
- **Git workflow best practices**  

## 🎯 What I Learned  
✅ The importance of **structuring and planning** before coding  
✅ Enhancing form **UX with CSS pseudo-classes**  
✅ Using **overlays** for better text readability  
✅ Strengthening **Git version control skills**  

## 🛠️ Technologies Used  
- HTML5  
- CSS3  
- Git & GitHub
